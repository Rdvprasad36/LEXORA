# Lexora — AI for Legal Assistance & Access
### PromptWars: Virtual (Exclusive Edition) Submission

A context-aware legal document navigator that shows you what matters to you, why it matters, and where your document proves it.

---

## What It Does
Upload a legal PDF or explore prepared case studies, declare your role and concern, and Lexora:
1. **Analyzes the document using Gemini AI** (`gemini-3.8-flash` via server-side `@google/genai`) with structured JSON schema validation.
2. **Returns a structured, schema-validated result** prioritized specifically for your context and role.
3. **Verifies every AI-generated claim** against the actual document text using a client-side deterministic tiered evidence matching engine (`evidenceMatcher.ts`).
4. **Shows you exactly where in the PDF each finding is sourced** — or honestly labels it "unverified".
5. **Provides guided actions** (Explain, Why does this matter?, Simplify, Risk assessment).
6. **Generates questions** to prepare for a qualified legal professional.

> *Disclaimer: This is not an AI lawyer. It provides informational analysis only.*

## Quick Start

### Prerequisites
- Node.js 22+
- Gemini API key configured in AI Studio Secrets (`GEMINI_API_KEY`)

### Setup & Running
```bash
git clone https://github.com/your-username/lexora.git
cd lexora
npm install
cp .env.example .env
# Ensure GEMINI_API_KEY is set in your environment / secrets
npm run dev
```

The app runs at `http://localhost:3000`. Without an API key or for instant testing, you can click **"Explore Prepared Demos (Instant)"** to try out two pre-configured supported contexts:
- **Small Business Tenant — Financial Exposure**
- **Landlord — Exit / Renewal Obligations**

## Architecture & Design Decisions

See the in-app **Architecture & Docs** modal for full design details.
- **No Database:** All state is ephemeral. Legal documents never leave your session or browser.
- **Dual Pipeline:** Gemini analysis (server) and evidence verification (client-side PDF.js/text engine) are fully independent.
- **Computed Evidence Status:** `evidence_status` is computed deterministically by code, not generated by the model.
- **Honest Uncertainty:** Unverified claims are shown, labeled, and never treated as verified.

## Security & Compliance
- **Server-Side API Key:** API key is never in client bundles, never in logs.
- **No dangerous HTML:** All text rendered through React's default safe escaping.
- **Ephemeral Processing:** PDF content is never persisted to any database.
