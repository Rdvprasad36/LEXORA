# ADR 0001: Frontend Stack (Vite + React + TypeScript)

## Status
Accepted

## Context
Contextualis requires a high-performance single-page application (SPA) capable of handling local PDF file processing, client-side text extraction via PDF.js, interactive highlighting, and real-time document reasoning.

## Decision
We use Vite + React + TypeScript.

## Consequences
- Fast HMR and build times.
- Strong type safety across client and server interactions.
- Excellent ecosystem support for PDF.js and Tailwind CSS.
